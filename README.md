# STOOP — 송골매의 삶

송골매가 되어 하늘에서 총알처럼 내리꽂아 사냥하고, 짝을 만나고, 새끼를 키워 혈통을 이어 가는 3D 라이프 시뮬레이션.
Godot 4.7 (Forward+ / 웹은 Compatibility), GDScript.

**▶ 브라우저에서 바로 플레이: https://gammja17.github.io/stoop/** (PC 크롬/엣지/파이어폭스 권장, 키보드+마우스)

미리보기: `docs/screenshots/` (장면별 스크린샷)

## 실행

- **웹**: https://gammja17.github.io/stoop/ (화면을 한 번 클릭하면 마우스가 잡힌다, Esc로 풀림)
- **빌드된 게임**: `builds/windows/STOOP.exe` 실행 (에디터에서 Windows 프리셋으로 내보내기)
- **에디터**: Godot 4.7로 이 폴더(`project.godot`)를 열고 F5
- 저장 파일: `%APPDATA%\Godot\app_userdata\STOOP\stoop_save.json`, 설정은 같은 폴더의 `settings.cfg`

## 조작

| 입력 | 동작 |
|---|---|
| 마우스 / 왼쪽 스틱 | 바라보는 곳으로 날아간다 (카메라는 마우스로 돌린 방향을 그대로 유지) |
| A / D | 좌우로 돌기. 빠르게 두 번 누르면 옆으로 구르기 (구애 비행 가산점) |

| F11 / F12 | 전체 화면 / 스크린샷 |

## 프롤로그 (튜토리얼)

새 게임에서 "알에서부터"를 고르면 둥지의 알 속에서 시작한다. 클릭해서 껍데기를 깨고 나오면, 몇 주 뒤 어미 매가
날갯짓 → 따라 날기 → 상승기류 타기 → 급강하 → 공중에서 먹이 받기 → 앉아서 먹기 → 첫 사냥 → 둥지로 돌아오기를
하나씩 가르친다. 대사는 "바위에 앉아(E) 먹어라(Q)"처럼 동작 바로 뒤에 키가 붙는다. 다 배우면 어미는 떠나고, 1년 뒤 봄부터 삶이 시작된다.
일시정지 메뉴에서 언제든 건너뛸 수 있다.

## 핵심 재미: 급강하

- **높이가 곧 속도.** 상승기류(반짝이는 기둥)나 날갯짓으로 높이를 벌고, 날개를 접으면 항력이 1/5로 줄어 최고 약 400 km/h까지 가속한다.
- **방향을 틀면 속도를 잃는다.** 날개를 접은 상태에선 선회력이 약하고, 빠를수록 G 한계 때문에 크게 돌 수 없다. 처음부터 잘 겨눌수록 빠르게 꽂힌다.
- **◇ 예측 지점.** 먹잇감이 아니라 "만날 지점"을 노린다 (실제 송골매도 미사일 유도 법칙과 같은 방식으로 추적한다는 연구가 있다).
- **위에서 뒤로 내리꽂기.** 빠르게 위에서 오는 매는 거의 못 알아챈다. 느리게 다가가면 알아채고 도망·회피(급선회)한다.
- **타격감.** 명중 순간 히트스톱 → 슬로모션 → 복귀, 깃털 폭발, 충격파 고리, 화면 흔들림·FOV 펀치·색수차, 합성 타격음. 250 km/h 이상은 **PERFECT STOOP** + 측면 킬캠.
- **빠져나오기.** 365 km/h에서 빠져나오려면 약 70 m가 필요하다. 지면이 가까우면 화면 가장자리가 붉게 번쩍이고 심장 소리가 난다.
- **맞힌 뒤.** 먹잇감이 떨어진다 → 공중에서 낚아채거나, 땅/물에서 천천히 스치며 줍는다. 갈매기가 가로채러 온다.

- **상승기류 자동 선회.** 기둥 안에서 마우스에서 손을 떼면 매가 알아서 중심을 돌며 올라간다(초당 약 6 m). 마우스를 움직이면 바로 직접 조종으로 돌아온다. 먹잇감을 겨누는 중에는 끼어들지 않는다.
- **손을 떼면 수평으로.** 조준을 가만히 두면 천천히 완만한 활공 자세로 돌아온다(급강하·급상승 조준은 건드리지 않는다).

## 먼 바다의 섬

본섬에서 동쪽으로 1.6~2.7 km. 바다 위엔 상승기류가 없으니 높이를 벌고 건넌다. 처음 가 본 섬은 안내가 뜨고, 세 곳을 다 가면 기록.

| 섬 | 모습 | 사는 것 |
|---|---|---|
| 바닷새섬 | 동쪽이 높은 절벽, 번식지 | **바다쇠오리**(수면 바로 위를 낮게 날다 가까이 가면 잠수), 절벽 비둘기, 번식기(봄·여름)엔 둥지를 지키는 갈매기 떼가 덤빈다. 동풍이 불면 절벽 앞에 능선 상승풍 |
| 물범 모래톱 | 낮은 모래섬 + 북쪽 바위 언덕 | 물범(가까이 낮게 날면 물로 뛰어든다), 도요새 떼(가을에 많다), **흰꼬리수리**(여름 빼고. 먹이를 든 매를 쫓아와 빼앗는다. 빠르게 들이받으면 물러난다) |
| 박쥐섬 | 좁고 높은 바위 기둥 섬, 서쪽 해식동굴 | 여름·가을 해 질 녘에 동굴에서 **박쥐 떼**가 쏟아져 나온다(지그재그로 날아 맞히기 어렵다, 날면서 먹을 수 있다). 새벽엔 돌아간다 |

바다에는 섬 사이를 오가는 돌고래 떼, 가끔 떠오르는 고래, 어선. 본섬에는 앉아 있거나 느리게 나는 매를 괴롭히는 **까마귀 떼**와, 땅에 떨어진 먹이를 물어 가고 땅에서 먹는 매에게 몰래 다가오는 **여우**가 산다.

## 삶의 한 해 (게임 루프)

| 계절 | 목표 | 사건 |
|---|---|---|
| 봄 (3일) | 침입자 매 쫓아내기 → 짝 구애(급강하 과시·먹이 선물·둥지 보여주기·울음) → 알 | 침입자는 위에서 급강하 공격 |
| 여름 (4일) | 새끼 먹이기 (둥지에 착지하거나 둥지 위에서 떨어뜨리기) | 밤에 수리부엉이 습격, 굶으면 새끼가 죽는다 |
| 가을 (3일) | 새끼 위에서 먹이를 떨어뜨려 사냥 가르치기 | 도요새 떼 이동, 찌르레기 군무 |
| 겨울 (2일) | 버티기 (눈, 배고픔 증가, 오리 사냥) | 연말 결산 |

- 나이를 먹으며 스태미나가 줄고, 수명(5~8년)이 다하면 죽는다. 굶주림·치명적 충돌(야생 난이도)로도 죽는다.
- 죽으면 **살아 있는 자식 중 하나로 다음 세대를 이어간다.** 교육을 잘 받은 자식일수록 능력치 보너스.
- 수컷: 작고 민첩 / 암컷: 3분의 1 더 커서 느린 속도로도 큰 먹잇감을 쓰러뜨린다.
- 보통 난이도: 치명상에도 기절 후 둥지에서 깨어남. 야생: 한 번의 실수가 죽음.

## 그 밖의 것

- **기록(업적) 20개**: 첫 사냥, 300/350 km/h 돌파, 완벽한 일격 10회, 네 종류 먹잇감, 3대째 혈통, 섬 탐험가, 바다쇠오리, 박쥐, 흰꼬리수리 쫓아내기 등. 모든 삶에 걸쳐 남는다.
- **설정**: 마우스 감도, 상하 반전, 볼륨 4종, 속도감 화면 효과·흔들림 강도(멀미 대비), 킬캠, 도움말, 그래픽 품질(낮음/보통/높음), 전체 화면, 수직 동기화, 하루 길이(6/8/12분), 언어(한국어/English).
- 창이 포커스를 잃으면 자동 일시정지. 둥지에서 잠들면 자동 저장.

## 세계

동쪽이 바다인 해안 섬 (약 2.8 km)과 동쪽 먼 바다의 작은 섬 셋. 둥지가 있는 해안 절벽과 해식 기둥, 갯벌(도요새·오리), 들판(찌르레기), 어촌과 등대(비둘기), 서쪽 산지.
낮/밤, 계절(나무 단풍·눈), 날씨(맑음·흐림·강풍·비·안개·눈), 바다에서 불어오는 바람이 절벽에 부딪혀 생기는 능선 상승풍.

                   mobber(까마귀·번식지 갈매기), sea_eagle(흰꼬리수리), fox(여우), sea_life(물범·돌고래·고래·어선·번식지)

                   critter_model(여우·물범·돌고래·고래), nest
scripts/fx/        fx.gd(깃털·충격파·물보라), speed_streaks, wing_trails
scripts/ui/        hud, reticle(조준·◇·표식), compass, 각 메뉴

tools/             개발용 자동 점검 (배포 빌드에서 제외)

## 개발용 자동 점검

```
godot --path . -- --autotest      # 주요 장면 스크린샷 → .shots/
godot --path . -- --lifetest      # 한 해 전체 흐름(짝→알→새끼→독립→결산→죽음→다음 세대)
godot --headless --path . -- --flighttest   # 비행 수치(활공, 상승기류, 급강하, 빠져나오기)
godot --headless --path . -- --bottest      # 입력만으로 사냥하는 봇
godot --path . -- --prologuetest  # 프롤로그 전체 자동 진행
godot --path . -- --islandtest    # 먼 섬 스크린샷 + 지도
godot --path . -- --animaltest    # 새 동물 행동 확인 (잠수, 떼 공격, 수리 추격, 여우, 박쥐, 고래)
godot --headless --path . -- --thermaltest  # 손 뗀 채 상승기류 자동 선회로 오르는 높이
godot --path . -- --perftest      # 무엇이 프레임을 먹는지 하나씩 꺼 보며 잰다
python tools/gen_ui.py            # 메뉴 씬(.tscn) 다시 생성
```
